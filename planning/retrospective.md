# Retrospective

The **Tic Tac Toe** project was an exciting and rewarding experience, allowing me to showcase my skills as a Front-End Developer while creating a classic game. This project offered valuable insights into my performance, processes, and areas for improvement. It highlighted my expertise in HTML, CSS, and JavaScript, while also pushing me to improve my problem-solving skills.

---

## Stop Doing

- Don’t spend too much time on unnecessary features. Focus on the core gameplay experience first.
- Avoid over-complicating the design—keep it simple and intuitive.

## Continue Doing

- **Continuous learning**: Continue to expand my knowledge of game development and front-end technologies.
- **Enhancing skills**: Keep improving my proficiency in HTML, CSS, JavaScript, and testing frameworks like Jest.

## Start Doing

- **Focusing more on solutions**: Explore more ways to enhance the user experience by incorporating feedback and adjusting features based on usability testing.
- **Including additional functionality**: Start planning for features like AI opponents or a scoreboard to make the game more dynamic.

---

## Lessons Learned

- **Plan the project thoroughly**: Take more time in the initial phases to define the game's logic and wireframe. This can save time later in the development process.
- **Create a wireframe**: Having a visual layout helped guide the design process and reduce confusion during development.
- **Read and understand code**: Review all the code and logic carefully, especially while debugging or adding new features.
- **Resolve conflicts early**: Make sure to sync work regularly with the GitHub repository and address conflicts as they arise to avoid delays.

---

### What parts of your plan went as expected?

- I was able to successfully implement the core gameplay mechanics (player turns, win/draw detection, and game reset).
- The project remained on schedule, and I solved problems as they came up.

### What parts of your plan did not work out?

- I had to adjust some aspects of the styling and responsiveness after testing on different devices.
- Some minor bugs were present in the initial version, but they were quickly fixed.

### Did you need to add things that weren't in your strategy?

- Yes, I added a **reset button** to restart the game after it ended, which wasn't initially in the plan but was necessary for a better user experience.

### Or remove extra steps?

- No, everything included in the strategy was essential for the project.

### Conclusion

The **Tic Tac Toe** project was a valuable learning experience, allowing me to refine my front-end development skills. Moving forward, I plan to continue improving the game by adding features like an AI opponent, enhancing responsiveness, and ensuring cross-browser compatibility. This project has strengthened my problem-solving abilities and reinforced the importance of thorough planning and testing.
